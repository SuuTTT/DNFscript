# QuestPilot Phase 1 task brief

**Objective:** Build an offline-only deterministic visual-agent vertical slice
and permission/business gates. **Budget:** US$0. **Allowed:** local Python,
official policy research, Git branch/push, and a portal status update.
**Prohibited:** commercial-game login or credentials, anti-cheat/CAPTCHA
bypass, PvP, payments, chat, trading, paid APIs, rented compute, merges, or a
public service deployment.

**Done condition:** 30 fixed mock chores complete at >=95%, zero unsafe
actions, and every uncertain state safely stops with an audit record. The
portal card links only verified evidence and the final remote commit.
